# Play sessions require collection ownership

Supersedes [ADR 0025](./0025-game-manager-collection-is-ownership-not-play-history.md). Every **play session** starts from a **collection** shelf item via **game detail**; café / friends’-shelf logging without ownership is out of scope. Chosen so session creation has a single owned-game entry path and the shelf stays the source of “what I can start,” accepting that non-owned plays need a later deliberate design if they return.
