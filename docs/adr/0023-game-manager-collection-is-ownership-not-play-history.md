# Game Manager collection is ownership, not play history

**Status**: superseded by [ADR 0024](./0024-game-manager-play-requires-collection-ownership.md)

**Play sessions** may record games the **account owner** does not own (cafés, friends’ shelves). The **collection** is an optional owned shelf, offered via **add to collection** (default on when not already owned)—not a requirement for logging a sitting. Chosen so history tracks what was played without lying about ownership.

*(Historical.)* ADR 0024 reverses this: recording a sitting now requires the title on the **collection** first.
