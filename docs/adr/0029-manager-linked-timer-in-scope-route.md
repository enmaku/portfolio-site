# Manager-linked timer launches on an in-scope Game Manager route

The **account owner** **timer leg** opens the Game Timer project surface at `/projects/game-manager/timer`, inside Game Manager’s install **scope**, so a home-screen Game Manager app can `router.push` to it and **continue to scoring** without leaving the PWA. Guest **join links** stay the canonical `/projects/game-timer?room=` URL. Chosen instead of overlapping manifest scopes (one install would claim the other app) or `window.open` / `location.assign` (iOS standalone does not hand same-origin URLs to the other home-screen icon). Browser-back sentinels must merge into Vue Router’s `history.state` (`current` required); replacing that object makes the HTML5 history adapter assign `https://<host>undefined`.

**Considered:** launching `/projects/game-timer` in-document (works in a browser tab, rejected by installed Game Manager scope); widening Game Manager `scope` to include Timer; opening the Timer PWA via a full navigation.
