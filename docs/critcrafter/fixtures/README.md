# CritCrafter fixtures

Two kinds, one direction of flow: Pathbuilder exports go in, schema-validated sheet JSON comes out.

- `pathbuilder-exports/` holds the inputs. See [its README](pathbuilder-exports/README.md) for the max-HP goldens.
- `src/features/critcrafter/fixtures/*.sheet.json` holds the viewer fixtures. They are generated by `npm run critcrafter:regen-fixtures` (`scripts/critcrafter-regenerate-fixtures.mjs`), which runs each export through the function and refuses to write a sheet that fails [sheet.schema.json](../sheet.schema.json). Never hand-edit them; re-run the script after a schema or function change. Until the function exists (#500) the script uses a stub that emits a minimal schema-valid sheet.

Test helpers (no code shared between the two sides, both validate with Ajv 2020-12, strict, `allowUnionTypes`):

- Function side (CommonJS): `functions/critcrafter/test/schemaHelpers.js`
- Viewer side (ESM): `src/features/critcrafter/test/sheetSchema.js`

Each exports `validateSheet`, `assertValidSheet`, `findSumInvariantViolations` and `assertSumInvariant` (every Stat has `sum(breakdown[].amount) === value`).

## What each export proves

Committed exports are the `{ success, build }` body with the character name replaced by `Fixture` (and the same name inside item labels); everything else is byte-for-byte. The six heroes come from the sibling `strength-of-thousands/heroes/*.json` (`build` only).

| File | Build | Proves |
| --- | --- | --- |
| `dwarf-fighter-toughness.json` | Dwarf Fighter 5 | Max HP 80: `bonushp` 0, `bonushpPerLevel` 1. Non-caster, no gear lists. |
| `dwarf-fighter-barbarian-resiliency.json` | Dwarf Fighter 5 | Max HP 86: flat `bonushp` 6 (not per level). |
| `anya.json` | Human Summoner 2 | Single spontaneous caster, focus pool, weapons and armor. |
| `cy-an-copperbottom.json` | Goblin Inventor 1 | Archetype pseudo-caster (`Archetype Wizard`), no focus. |
| `lithrei-woeborn.json` | Human Oracle / Investigator 2 | Dual class line, `Other Spells (Staves etc)` pseudo-caster, `Archetype Oracle`, focus. |
| `solanum-calabash.json` | Leshy Magus 1 | Prepared caster with focus. |
| `taraan-skyseeker.json` | Tengu Cleric / Witch 2 | Dual class, `Cleric Font`, familiar, `mods` (Diplomacy, Religion), item potency and resilient values. |
| `yggostrus.json` | Dragonet Summoner 1 | `Homing Drake` pseudo-caster beside the real one. |

None of these has been hand-verified against Pathbuilder's own screen except the two Dwarf Fighter HP totals.

## Missing exports and synthetic fallbacks

Real exports still wanted. Until each arrives, a hand-built synthetic build in the function tests covers it.

- [ ] Pet or companion. Fallback: a build with a populated `pets` entry (expect no stat block, only familiar abilities as actions).
- [ ] Eidolon (not in `pets`). Fallback: a Summoner with eidolon-related `specials`; expect it ignored without failing.
- [ ] Runes on gear. Fallback: weapon and armor potency, striking and resilient values set; check attack, damage dice and AC breakdown lines.
- [ ] High-rank caster. Fallback: a caster with `perDay` populated up to rank 9 and spells at ranks 8 and 9; check slot keys `slots:<casterKey>:<rank>`.
